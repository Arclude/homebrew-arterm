# homebrew-arterm

Homebrew tap for [Arterm](https://github.com/Arclude/Arterm-CLI), a terminal AI
coding agent.

```bash
brew install arclude/arterm/arterm
```

`Formula/arterm.rb` is written by the CLI repository's release workflow on every
tag, with the URLs and SHA-256 sums of that release's macOS and Linux tarballs.
Edit it there, not here: a manual change is overwritten by the next release.
